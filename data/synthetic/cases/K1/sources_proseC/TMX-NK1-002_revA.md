## 3 Test methods

Boil time is tested per TM-NK1-031 (Boil time measurement); spec reference ≤ 250 s for 1.0 L from 20 °C; conditions: Standard, Hot, Cold.

Temperature hold accuracy is tested per TM-NK1-032 (Keep-warm temperature logging); spec reference 70 °C ± 3 °C for 30 min; conditions: Standard, Hot, Cold.

Lid opening force is tested per TM-NK1-033 (Lid release force test); spec reference 15 N to 35 N; conditions: Standard, Cold.

Auto shut-off is tested per TM-NK1-034 (Auto shut-off functional check); spec reference see PRS; conditions: Standard, Hot, Cold.

Dry-boil protection is tested per TM-NK1-035 (Dry-boil cut-off check); spec reference see PRS; conditions: Standard.

Handle surface temperature is tested per TM-NK1-036 (Handle surface temperature scan); spec reference ≤ 45 °C after 3 consecutive boils; conditions: Standard, Hot.

Water level readability is tested per TM-NK1-112 (Visual readability inspection); spec reference see PRS; conditions: Standard.

Cord retraction endurance is tested per TM-NK1-038 (Cord retraction cycling); spec reference ≥ 5,000 cycles without damage; conditions: Standard, Cold.
