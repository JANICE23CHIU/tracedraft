## 3 Test methods

Airflow output is tested per TM-OF2-011 (Airflow chamber measurement); spec reference ≥ 1.8 m³/min at speed 3; conditions: Standard, Humid, Cold.

Noise level is tested per TM-OF2-012 (Sound pressure measurement); spec reference ≤ 45 dB(A) at speed 1, 1 m; conditions: Standard, Humid.

Oscillation angle is tested per TM-OF2-013 (Oscillation sweep measurement); spec reference 80° ± 5°; conditions: Standard, Cold.

Tip-over switch is tested per TM-OF2-014 (Tilt cut-off functional check); spec reference see PRS; conditions: Standard, Humid, Cold.

Button actuation force is tested per TM-OF2-015 (Button force gauge test); spec reference 3 N to 6 N; conditions: Standard, Humid.

Remote control range is tested per TM-OF2-087 (IR remote range check); spec reference see PRS; conditions: Standard.

Guard finger probe is tested per TM-OF2-016 (Accessibility probe test); spec reference see PRS; conditions: Standard.
